#Overview

MindTrack is a simple python project aimed at beginners that enables users to track their emotional wellbeing via simple terminal-based interactions.
In this application, users can write journal entries, log their daily mood, get positive affirmations and take a stress level questionnaire.
It is lightweight and easy to run, as it stores all the data locally in .txt and .csv files, without the need for installing additional packages.

Features

It allows our users to:

- Write and save their thoughts in a journal

-Log their moods to track
-get random positive affirmations whenever they need it

-take a simple quiz to find out their level of stress
